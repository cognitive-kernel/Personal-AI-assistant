# معماری اولیه

> این سند شرح اولیهٔ معماری است و مرجع نهایی وضعیت زیرسامانهٔ یادگیری نیست. برای رفتار جاری، محدودیت‌ها و نقشهٔ راه یادگیری به [راهنمای جامع زیرسامانه یادگیری](LEARNING.md) مراجعه کنید؛ برای وضعیت کلی پروژه به [PROJECT_STATUS.md](PROJECT_STATUS.md) مراجعه کنید.

## اصول
- اجرای محلی و اولویت CPU؛ استفاده از GPU تا زمان بررسی پشتیبانی backend فعال نمی‌شود.
- داده‌های پایدار در SQLite و مطابق schemaهای نسخه‌بندی‌شده نگهداری می‌شوند؛ مرزهای دقیق ذخیره‌سازی باید با کد جاری تطبیق داده شوند.
- لایه مدل از طریق adapter جداگانه قابل تعویض است؛ نسخه اول از Ollama استفاده می‌کند.
- ورودی کاربر و خروجی مدل، منبع معتبر تأییدشده فرض نمی‌شوند.
- هر کار یادگیری وضعیت، منشأ و خطا دارد؛ خروجی مدل با دانش تأییدشده یکی نیست.

## اجزا
- app/config.py: پیش‌فرض‌ها و متغیرهای محیطی.
- app/hardware.py: تشخیص CPU/RAM و محاسبه محدودیت‌های محافظه‌کارانه.
- app/db.py: تنظیمات و ساختار پایگاه داده یادگیری در فایل‌های مجزا.
- app/ollama.py: ارتباط HTTP محلی با Ollama، فهرست مدل‌ها و گفتگو.
- زیرسامانهٔ یادگیری، دوره‌ها، ارزیابی، مرور، شواهد و دانش factual: شرح جاری و نقاط ورود کد در [راهنمای جامع یادگیری](LEARNING.md).
- app/main.py: API و رابط اولیه مرورگر.

## مرزهای معماری و ایمنی
- جزئیات جاری قابلیت‌ها، محدودیت‌ها و کارهای باقی‌ماندهٔ یادگیری در [راهنمای جامع یادگیری](LEARNING.md) نگهداری می‌شود تا این سند شرح تکراری یا متناقض نداشته باشد.
- API محلی احراز هویت عمومی/راه‌دور ندارد؛ آن را روی شبکهٔ عمومی منتشر نکنید. برای وضعیت دقیق مرزهای دسترسی به [وضعیت پروژه](PROJECT_STATUS.md) مراجعه کنید.
