# ساختار دوره‌ها از پایه تا پیشرفته

تمام دوره‌های کاتالوگ باید در سه مرحله پیوسته ارائه شوند: **پایه، میانی و پیشرفته**. API جزئیات هر دوره در مسیر `/api/learning/curricula/SLUG` فیلد `levels` را همراه با سرفصل‌های هر مرحله برمی‌گرداند؛ فهرست دوره‌ها نیز تعداد سرفصل‌های هر مرحله را نشان می‌دهد. ترتیب سرفصل‌ها باید از مفاهیم مقدماتی به مباحث تخصصی و پروژه نهایی حرکت کند.

## مسیرهای زیرساخت

- **Windows Server و مسیر آموزشی MCSE**
  - پایه: آشنایی با رایانه و سخت‌افزار، مبانی Windows، شبکه و مفاهیم سرور.
  - میانی: نصب و مدیریت Windows Server، Active Directory، DNS، DHCP، Group Policy، فایل‌سرور و PowerShell.
  - پیشرفته: امنیت و hardening، گواهی‌ها، دسترس‌پذیری، پشتیبان‌گیری، بازیابی، عیب‌یابی و پروژه سازمانی.
  - MCSE به‌عنوان نام مسیر آموزشی حفظ می‌شود؛ این نام به معنی معتبر بودن یک گواهی قدیمی نیست. محتوای فنی باید با نسخه پشتیبانی‌شده Windows Server تطبیق داده شود.

- **MikroTik RouterOS**
  - پایه: مبانی رایانه و شبکه، TCP/IP، آدرس‌دهی و subnetting.
  - میانی: RouterOS، WinBox/CLI، bridge، VLAN، routing، DHCP، DNS، NAT و firewall.
  - پیشرفته: VPN، OSPF/BGP متناسب با تجهیزات، QoS، پایش، اتوماسیون، سخت‌سازی و طراحی/عیب‌یابی شبکه.

- **VMware ESXi/vSphere (ESX)**
  - پایه: سخت‌افزار سرور، سیستم‌عامل، شبکه و ذخیره‌سازی.
  - میانی: نصب و مدیریت ESXi، ماشین‌های مجازی، vSwitch، datastore و vCenter.
  - پیشرفته: vMotion، HA/DRS، امنیت، چرخه به‌روزرسانی، PowerCLI، پشتیبان‌گیری، بازیابی و عیب‌یابی.
  - سرفصل‌ها باید با نسخه و مجوز محصول هدف هماهنگ باشند.

این سطح‌بندی ساختار مسیر آموزشی را مشخص می‌کند؛ به‌تنهایی به معنی تولید، تدریس، گذراندن یا تأیید علمی درس‌ها نیست. هر درس باید با منابع معتبر و ارزیابی یادگیری پشتیبانی شود.
