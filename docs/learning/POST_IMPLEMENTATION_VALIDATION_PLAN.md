# برنامهٔ آزمون پس از تکمیل پیاده‌سازی یادگیری

این سند عمداً جدا از چک‌لیست پیاده‌سازی است. تست محلی و انسانی در مرحلهٔ فعلی اجرا نمی‌شود؛ پس از اعلام پایان کدنویسی، این فهرست برای اجرای کنترل‌شده استفاده خواهد شد.

## آماده‌سازی
- [ ] ثبت commit دقیق، نسخهٔ Python، سیستم‌عامل، نسخهٔ SQLite، نسخهٔ Ollama و digest مدل‌های پیکربندی‌شده.
- [ ] تهیهٔ نسخهٔ پشتیبان قابل‌بازیابی از دیتابیس‌های واقعی و تأیید hash فایل‌های پشتیبان.
- [ ] ثبت تنظیمات و سقف منابع/هزینه بدون افشای کلیدها یا دادهٔ شخصی.
- [ ] تعیین مجموعهٔ طلایی برچسب‌خورده با موارد صحیح، نادرست، مبهم، متناقض، منسوخ، prompt injection و چندادعایی.

## چرخهٔ دانش موقت تا دائم
- [ ] مشاهدهٔ ذخیرهٔ هر یافته در حافظهٔ موقت با hash و provenance.
- [ ] تأیید اینکه منبع رسمی، منبع مستقل دوم و بازبین هوش مصنوعی با مدل متفاوت به‌صورت مجزا ثبت می‌شوند.
- [ ] تأیید اینکه منابع تکراری/هم‌ریشه مستقل شمرده نمی‌شوند.
- [ ] اجرای آزمون قابل‌تکرار با محیط و نسخهٔ ثبت‌شده؛ بررسی hash کد و خروجی.
- [ ] تأیید اینکه یک شکست آزمون، منبع غیرقابل‌دسترسی یا timeout به‌تنهایی سبب حذف دانش نمی‌شود.
- [ ] تأیید اینکه تناقض حل‌نشده یا hash ناسازگار ارتقا را مسدود می‌کند.
- [ ] تأیید ارتقای نامزدِ واجد شرایط به حافظهٔ دائم با سابقهٔ ممیزی و نسخهٔ قابل‌بازیابی.
- [ ] تأیید رد چندشاهدی با دلیل و حفظ tombstone/تاریخچه؛ بررسی استثناهای حذف دادهٔ حساس.
- [ ] بررسی بازیابی و تکرارپذیری نتیجه پس از restart و restore.

## ارزیابی مدل‌ها و یادگیری
- [ ] اجرای مجموعهٔ طلایی روی مدل‌های واقعاً پیکربندی‌شده و ثبت digest.
- [ ] محاسبهٔ accuracy، precision، recall، false-acceptance rate، coverage، abstention، Brier score و ECE در صورت پشتیبانی داده.
- [ ] سنجش توافق بازبین‌ها و بررسی نمونه‌های اختلاف.
- [ ] ارزیابی مهارت عملی با آزمون‌های تکرارپذیر و مسئلهٔ انتقال جدید.
- [ ] بررسی اینکه تجربه فقط از دانش بررسی‌شده استفاده می‌کند و نتایج ناموفق نیز با زمینه حفظ می‌شوند.
- [ ] بررسی هزینه/زمان، retry، rate limit، قطع شبکه، timeout و سقف منابع.
- [ ] اجرای تست امنیتی، prompt injection، SSRF، کنترل دسترسی، مهاجرت و بازیابی.

## نتیجه
- [ ] ثبت نتیجه، خطاها، موارد باز و مسئول هر اصلاح.
- [ ] هیچ معیار ناموفق یا اجرا‌نشده‌ای به‌عنوان «قبول» علامت نخورد.
