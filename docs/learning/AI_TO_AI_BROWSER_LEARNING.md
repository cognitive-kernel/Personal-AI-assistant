# یادگیری هوش‌به‌هوش از طریق Chrome و ChatGPT

## هدف و مرزبندی

این قابلیت فاز اول زیرسامانهٔ یادگیری است. برنامه از طریق Chrome DevTools Protocol به یک نشست محلی Chrome که کاربر خودش راه‌اندازی کرده متصل می‌شود، در رابط وب ChatGPT درخواست سرفصل می‌فرستد، پاسخ سرفصل را ذخیره می‌کند، برای هر سرفصل درخواست درس مستقل می‌فرستد و پاسخ را بلافاصله ذخیره می‌کند. مسیر فعلی یادگیری با Ollama و مسیرهای پژوهش/اعتبارسنجی حذف یا جایگزین نشده‌اند؛ فاز دوم پژوهش مستقل بعداً توسعه می‌یابد.

## پیش‌نیاز و راه‌اندازی

1. برنامه را در محیط مجازی پروژه نصب کنید:
   `python -m pip install -e ".[browser]"`
2. Chrome را با پروفایل اختصاصی و پورت DevTools روی loopback اجرا کنید. برای نمونه در Windows (مسیر Chrome را با محل نصب خودتان تطبیق دهید):
   ```powershell
   & "$env:ProgramFiles\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222 --user-data-dir="$env:LOCALAPPDATA\PersonalAI\ChromeProfile"
   ```
   اگر Chrome در مسیر دیگری نصب شده، همان فایل اجرایی را استفاده کنید.
3. در پنجرهٔ جداگانهٔ Chrome به `https://chatgpt.com/` بروید و خودتان وارد حساب شوید. صفحه را باز نگه دارید.
4. در داشبورد، مسیر «یادگیری هوش‌به‌هوش» را انتخاب کنید، موضوع، نشانی `http://127.0.0.1:9222` و حداکثر تعداد سرفصل را ثبت کنید.
5. فهرست دوره‌ها وضعیت هر درس را نشان می‌دهد. اگر برنامه یا Chrome متوقف شود، دوره ناقص به وضعیت interrupted می‌رود؛ از گزینهٔ ادامه/تلاش دوباره استفاده کنید. درس‌های تکمیل‌شده نگه داشته می‌شوند و فقط درس‌های ناقص دوباره درخواست می‌شوند.

## ذخیره‌سازی و قابلیت اعتماد

- migration 33 جدول‌های `browser_learning_courses` و `browser_learning_lessons` را در پایگاه دادهٔ یادگیری ایجاد می‌کند.
- پاسخ سرفصل، متن درس، ترتیب، وضعیت، زمان‌ها، URL منبع ChatGPT و SHA-256 درخواست/پاسخ ذخیره می‌شوند.
- محتوا با منشأ `https://chatgpt.com/` ثبت می‌شود، اما این به معنی منبع رسمی فنی یا تأیید علمی نیست. متن‌ها تا ارزیابی مستقل، خروجی خامِ تولیدشده محسوب می‌شوند.
- هر بار فقط یک دورهٔ هوش‌به‌هوش می‌تواند در صف/حال اجرا باشد تا پیام‌ها بین دوره‌ها قاطی نشوند.
- نشانی DevTools فقط HTTP loopback مجاز است؛ میزبان راه‌دور، credential، مسیر اضافی، query و fragment رد می‌شوند. پورت DevTools دسترسی قدرتمندی به نشست مرورگر می‌دهد؛ آن را روی LAN/اینترنت bind یا منتشر نکنید و از پروفایل اختصاصی استفاده کنید.
- برنامه کلیدواژه‌ها/پاسخ را از DOM رابط ChatGPT می‌خواند؛ تغییرات UI یا selectorهای ChatGPT ممکن است نیاز به اصلاح داشته باشند. این مسیر API رسمی ChatGPT نیست و به نشست واردشدهٔ کاربر و دسترسی وب ChatGPT وابسته است.
- اگر Playwright نصب نباشد، اتصال CDP در دسترس نباشد، کاربر وارد نشده باشد یا پاسخ در مهلت تعیین‌شده کامل نشود، کار ناموفق ثبت می‌شود؛ محتوای ناقص به‌عنوان درس تکمیل‌شده علامت نمی‌خورد.

## اعتبارسنجی باقی‌مانده

آزمون‌های واحد URL محلی، پارس سرفصل، ماندگاری و ادامهٔ دوره را پوشش می‌دهند. تست end-to-end با Chrome واقعی و نشست مجاز ChatGPT باید روی ماشین هدف انجام شود؛ CI بدون نشست کاربر نباید وارد حساب یا به ChatGPT ارسال زنده انجام دهد. نتیجهٔ تست واحد به‌تنهایی پایداری selectorهای فعلی، صحت محتوای تولیدشده یا آمادگی عملیاتی را اثبات نمی‌کند.
