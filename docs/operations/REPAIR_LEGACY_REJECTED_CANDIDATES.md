# بازیابی امن نامزدهای یادگیری ردشدهٔ قدیمی

این ابزار فقط برای رکوردهایی است که نسخهٔ قدیمی کد آن‌ها را با وضعیت `rejected_after_review` علامت‌گذاری کرده و بعضی فیلدها را خالی کرده است. ابزار هیچ داده‌ای را حذف نمی‌کند و هیچ نامزدی را تأیید یا منتشر نمی‌کند.

## پیش‌نیازهای اجباری

1. برنامه و تمام workerهای یادگیری را متوقف کنید.
2. از فایل دیتابیس یادگیری یک نسخهٔ پشتیبان خارج از پوشهٔ برنامه تهیه کنید.
3. صحت فایل پشتیبان را بررسی کنید و نسخهٔ اصلی را دست‌نخورده نگه دارید.
4. مسیر دیتابیس باید همان مسیری باشد که تنظیمات فعلی برنامه استفاده می‌کند.

## مرحلهٔ اول: فقط گزارش‌گیری

از ریشهٔ مخزن اجرا کنید:

```powershell
python scripts/repair_legacy_rejected_candidates.py
```

این حالت فقط‌خواندنی است. برای هر candidate شناسه، فیلدهای قابل بازیابی، فیلدهای غیرقابل بازیابی و نتیجهٔ بررسی hash را گزارش می‌کند. هیچ تغییری در دیتابیس ایجاد نمی‌شود.

## مرحلهٔ دوم: اعمال بازیابی پس از بررسی گزارش

فقط اگر نسخهٔ پشتیبان معتبر است و گزارش dry-run با رکوردهای مورد انتظار تطبیق دارد:

```powershell
python scripts/repair_legacy_rejected_candidates.py --apply
```

ابزار فقط این داده‌ها را بازیابی می‌کند:

- متن candidate از `learning_jobs.lesson`، فقط وقتی SHA-256 آن دقیقاً با `content_sha256` ثبت‌شده در candidate برابر باشد.
- URLهای منبع از رکوردهای باقی‌ماندهٔ `learning_evidence` با نوع `web_page` و فقط URLهای HTTPS.
- گزارش کیفیت از `learning_jobs.quality_json`، اگر JSON معتبر و غیرخالی باشد.

ابزار این موارد را بازسازی یا حدس نمی‌زند:

- متن خام منبعی که قبلاً از `learning_source_text` حذف شده است.
- ارزیابی‌ای که قبلاً از `learning_jobs.assessment_json` پاک شده است.
- طرح آزمونی که قبلاً خالی شده است.
- نسخهٔ اصلی رکورد `knowledge_items` که شمارهٔ نسخهٔ آن دیگر قابل اثبات نیست.

این فیلدها در گزارش به‌عنوان غیرقابل بازیابی مشخص می‌شوند. candidate همچنان ردشده و غیرقابل ارتقا باقی می‌ماند؛ اصلاح علمی باید با یک candidate نسخه‌دار جدید انجام شود.

## کنترل پس از اجرا

پس از اعمال، حالت dry-run را دوباره اجرا کنید. ابزار باید رکوردهای بازیابی‌شده را دوباره تغییر ندهد. سپس از API وضعیت candidate، hash، URLها و تاریخچهٔ بازبینی را بررسی کنید. این ابزار جایگزین backup/restore یا تست پذیرش نیست.
