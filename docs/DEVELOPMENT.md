# راه‌اندازی محیط توسعه

نیازمندی سیستم: Python 3.11 یا جدیدتر و Ollama. نصب Ollama به‌دلیل تفاوت‌های سیستم‌عامل جداگانه انجام می‌شود؛ لانچر آن را بررسی می‌کند و اگر در دسترس نباشد، اجرای برنامه را متوقف می‌کند.

## اجرای خودکار

از ریشه مخزن اجرا کنید:

```bash
python run.py
```

لانچر با کتابخانه‌های استاندارد پایتون اجرا می‌شود و پیش از بالا آمدن برنامه:
1. محیط مجازی `.venv` را می‌سازد یا از محیط موجود استفاده می‌کند.
2. وابستگی‌های تعریف‌شده در `pyproject.toml` را بررسی می‌کند.
3. اگر بسته‌ای کم باشد، بسته‌ها و وابستگی‌هایشان را در `prerequisites/wheels` دانلود و از همان پوشه نصب می‌کند.
4. وجود Ollama و دسترسی به سرویس آن را بررسی می‌کند.
5. اگر مدل تنظیم‌شده نصب نباشد، آن را با `ollama pull` دریافت می‌کند.
6. فقط پس از موفقیت مراحل بالا، سرور محلی را اجرا می‌کند.

گزینه‌ها:

- `python run.py --check-only`: بررسی و آماده‌سازی پیش‌نیازها بدون اجرای سرور.
- `python run.py --dev`: علاوه بر وابستگی‌های اصلی، وابستگی‌های توسعه و آزمون را هم آماده می‌کند.
- متغیر `OLLAMA_MODEL` نام مدل موردنیاز را تغییر می‌دهد؛ پیش‌فرض `qwen2.5:7b` است.

## اجرای آزمون‌ها

```bash
python run.py --dev --check-only
.venv/bin/python -m pytest
```

در Windows از `.venv\\Scripts\\python.exe -m pytest` استفاده کنید.

پوشه `prerequisites/wheels` و محیط `.venv` محلی هستند و نباید وارد Git شوند. اگر دریافت بسته‌ها ناموفق باشد، برنامه اجرا نمی‌شود تا از اجرای ناقص جلوگیری شود.

پایگاه داده‌ها در اولین راه‌اندازی ساخته می‌شوند. مسیرهای پیش‌فرض `data/settings.db` و `data/learning.db` هستند. فایل‌های محلی نباید وارد Git شوند.
