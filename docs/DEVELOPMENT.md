# راه‌اندازی محیط توسعه

نیازمندی‌ها: Python 3.11 یا جدیدتر و Ollama نصب‌شده.

## اجرا
1. یک محیط مجازی بسازید و فعال کنید.
2. وابستگی‌ها را نصب کنید:
   python -m pip install -e ".[dev]"
3. در صورت نیاز، متغیرهای فایل .env.example را در محیط خود تنظیم کنید.
4. سرویس Ollama را اجرا کنید و مدل پیش‌فرض را دریافت کنید:
   ollama pull qwen2.5:7b
5. برنامه را اجرا کنید:
   uvicorn app.main:app --host 127.0.0.1 --port 8000
6. رابط در http://127.0.0.1:8000 و مستندات API در http://127.0.0.1:8000/docs در دسترس‌اند.
