این گزارش فقط نتایجی را ثبت می‌کند که خروجی فرمان یا لاگ اجرای کاربر برایشان ارائه شده است. نتیجهٔ تست خودکار، اجرای موفق سرور و پاسخ HTTP به‌تنهایی اثبات‌کنندهٔ موفقیت end-to-end ارتباط واقعی با ChatGPT یا صحت علمی درس‌ها نیست.

## 1. تست‌های خودکار

### تست‌های اختصاصی AI Learning

فرمان اجراشده:

```powershell
python -m pytest tests/test_ai_learning_module.py tests/test_ai_learning_duplicates.py tests/test_ai_learning_outline_completeness.py tests/test_ai_learning_ui.py tests/test_ai_learning_retrieval_boundary.py -q
```

نتیجهٔ ثبت‌شده: همهٔ ۷۹ مورد نمایش‌داده‌شده موفق بودند؛ هیچ شکست یا traceback در خروجی ارسالی دیده نشد.

### کل مجموعهٔ تست‌ها

فرمان اجراشده:

```powershell
python -m pytest -q
```

نتیجهٔ ثبت‌شده:
- اجرای جمع‌آوری‌شده به ۱۰۰٪ رسید.
- هیچ تست ناموفقی در خروجی دیده نشد.
- چهار نشانگر skip در خروجی قابل مشاهده بود.
- خروجی ارسالی شامل خلاصهٔ نهایی تعداد passها و علت skipها نبود؛ بنابراین این گزارش عدد دقیق pass کل مجموعه یا دلیل skipها را ادعا نمی‌کند.

### نصب editable

فرمان `python -m pip install -e ".[dev]"` با موفقیت پایان یافت و بستهٔ `personal-ai-assistant==0.1.0` نصب شد. این نصب مربوط به Python فراخوانی‌شده از PowerShell بود؛ لانچر برنامه نیز محیط مجازی پروژه را ساخت/استفاده کرد. این دو محیط را بدون بررسی مسیر `python.exe` یکسان فرض نکنید.

## 2. اجرای واقعی لانچر و رابط

فرمان اجراشده:

```powershell
$env:AI_LEARNING_ENABLED = "1"
python run.py
```

شواهد لاگ ارسالی:
- بررسی وابستگی‌ها موفق بود و `No broken requirements found.` گزارش شد.
- لانچر مدل‌های Ollama موجود را فهرست کرد؛ از جمله `qwen2.5:7b`.
- سرور Uvicorn با موفقیت روی `http://127.0.0.1:8000` بالا آمد.
- startup رویداد `startup_queue_recovery` را با وضعیت `idle` و بدون `run_id` ثبت کرد؛ این فقط نشان می‌دهد در آن شروع، اجرای صف‌شده‌ای برای بازیابی گزارش نشده است.
- درخواست `GET /ai-learning` پاسخ `200 OK` گرفت.
- فایل‌های `style.css` و `app.js` پاسخ `200 OK` گرفتند.
- درخواست‌های `GET /api/ai-learning/courses`، `/api/ai-learning/courses/1`، `/api/ai-learning/courses/1/runs?limit=50` و `/api/ai-learning/control` پاسخ `200 OK` گرفتند.
- درخواست `GET /favicon.ico` پاسخ `404 Not Found` گرفت. این خطا در لاگ مشاهده شد و در آن لحظه مانع بالا آمدن صفحه یا پاسخ APIهای ذکرشده نشد؛ رفع آیکون در صورت نیاز یک کار رابطی جداگانه است.

تنظیم `$env:AI_LEARNING_ENABLED = "1"` فقط برای همان نشست PowerShell اعمال می‌شود و به‌خودی‌خود فایل `.env` را تغییر نمی‌دهد. در لاگ ارائه‌شده، مقدار `AI_LEARNING_RETRIEVAL_ENABLED` تنظیم یا فعال نشده است؛ این گزارش فعال بودن بازیابی در چت اصلی را ادعا نمی‌کند.

## 3. وضعیت پذیرش دستی

موارد زیر در شواهد ارائه‌شده هنوز end-to-end تأیید نشده‌اند:

- دریافت واقعی فهرست از رابط ChatGPT و ثبت کامل آن در پایگاه داده.
- بازخوانی همان فهرست و اثبات جلوگیری عملی از تکرار از طریق UI/worker.
- دریافت متن کامل یک درس، ذخیرهٔ پایدار، بازکردن دوباره و مشاهدهٔ نسخهٔ ذخیره‌شده.
- باز و بسته شدن منوی کاتالوگ و زیرمنوها پس از تغییر داده یا رندر مجدد.
- تأیید/رد سرفصل و اثبات اینکه تولید درس فقط بعد از تأیید صریح شروع می‌شود.
- رفتار در timeout، قطع شبکه، ورود/تأیید انسانی، راه‌اندازی مجدد در میانهٔ کار و بازیابی صف.
- علت چهار تست skip‌شده.

این‌ها باید با مرورگر و سرویس‌های واقعی روی میزبان هدف بررسی و نتیجهٔ هر مورد جداگانه ثبت شود. تا آن زمان وضعیت پذیرش عملیاتی ماژول «جزئاً آزمایش‌شده؛ پذیرش end-to-end باز است» است.

## 4. چک‌لیست ادامهٔ آزمون

- [ ] در `/ai-learning` یک دورهٔ آزمایشی انتخاب/ایجاد کنید و دریافت outline را اجرا کنید.
- [ ] نتیجه را در UI و پس از refresh بررسی کنید؛ صرف نمایش پاسخ را با ذخیرهٔ پایدار اشتباه نگیرید.
- [ ] همان outline را دوباره اجرا کنید و بررسی کنید عنوان تکراری در دوره یا همان batch ایجاد نشود.
- [ ] یک سرفصل را صریحاً تأیید کنید؛ متن درس را دریافت کنید؛ سپس صفحه را refresh کنید و ذخیرهٔ پایدار را بررسی کنید.
- [ ] منوی «فهرست موضوعات، سرفصل‌ها و درس‌ها» و زیرمنوهای سرفصل/درس را باز و بسته کنید.
- [ ] در محیط آزمایشی قطع شبکه/timeout و راه‌اندازی مجدد را امتحان کنید؛ دیتابیس‌ها را دستی حذف یا بازسازی نکنید.
- [ ] علت skipها را با اجرای `python -m pytest -rs -q` ثبت کنید.
- [ ] خروجی نهایی آزمون دستی را همراه با خطاهای UI و لاگ PowerShell به این گزارش اضافه کنید.

## 5. ملاحظات ایمنی

- `AI_LEARNING_RETRIEVAL_ENABLED=0` را در آزمون اولیه نگه دارید؛ دانش آزمایشی را به مسیر پاسخ چت اصلی متصل نکنید.
- سرور را فقط روی loopback نگه دارید؛ به LAN یا اینترنت در معرض دسترسی قرار ندهید.
- دیتابیس‌های موجود را حذف، بازنشانی یا به‌صورت دستی مهاجرت ندهید.
- دریافت و ذخیرهٔ محتوا به معنی تأیید علمی آن نیست؛ بازبینی محتوا و انتشار باید صریح بماند.
