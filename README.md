# Personal AI Assistant

دستیار هوش مصنوعی شخصی با رویکرد **local-first**؛ هدف این مخزن ساخت تدریجی یک Agent قابل توسعه، قابل آزمون و سازگار با منابع سخت‌افزاری سیستم است.

## سخت‌افزار هدف
- RAM: 32 GB
- CPU: Intel Core i5-12400 (12th Gen)
- GPU: Intel Integrated Graphics، حافظه گزارش‌شده 128 MB

برنامه منابع واقعی را هنگام اجرا تشخیص می‌دهد، تعداد thread و context را محدود می‌کند و GPU را به‌صورت پیش‌فرض مجبور به استفاده نمی‌کند. اجرای کارهای سنگین باید بودجه منابع داشته باشد.

## وضعیت فعلی
نسخه اولیه شامل این موارد است:
- اتصال محلی به Ollama برای گفتگو و فهرست مدل‌های نصب‌شده.
- تشخیص CPU/RAM و محدودیت محافظه‌کارانه context/thread.
- پایگاه داده تنظیمات و پایگاه داده یادگیری جدا از هم.
- ایجاد کار یادگیری، تولید یادداشت و سؤال‌های ارزیابی، ثبت منشأ خروجی و نگهداری نسخه‌بندی‌شده دانش با وضعیت اولیه تأییدنشده.
- رابط ساده مرورگر و API قابل مشاهده در مسیر /docs.
- آزمون‌های پایه برای جداسازی داده‌ها و محدودیت منابع.

**محدودیت مهم:** یادگیری از وب، اعتبارسنجی مستقل منابع، آزمون مستقل اثبات یادگیری، زمان‌بندی، RAG و صف پایدار هنوز کامل نشده‌اند. خروجی مدل به‌تنهایی دانش تأییدشده محسوب نمی‌شود.

## شروع سریع
Python 3.11+ و Ollama نصب کنید؛ سپس:

```bash
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# Linux/macOS:
source .venv/bin/activate

python -m pip install -e ".[dev]"
ollama pull qwen2.5:7b
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

رابط: http://127.0.0.1:8000  
مستندات API: http://127.0.0.1:8000/docs

برای جزئیات به docs/DEVELOPMENT.md و docs/ARCHITECTURE.md مراجعه کنید. نقشه کامل یادگیری در docs/LEARNING.md قرار دارد.
