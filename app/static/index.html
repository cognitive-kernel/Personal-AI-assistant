تنظیمات محلی
فهرست مدل‌ها از Ollama محلی خوانده می‌شود. فیلدهای مدل هم قابل انتخاب از فهرست و هم قابل تایپ دستی هستند؛ نام دستی لازم نیست در فهرست نصب‌شده‌ها باشد. تنظیم هر بخش مستقل ذخیره می‌شود. مدل، context، thread و timeout در درخواست بعدی استفاده می‌شوند؛ تغییر تعداد کارهای هم‌زمان پس از راه‌اندازی مجدد برنامه اعمال می‌شود.

سقف مستقل استفاده از منابع سخت‌افزاری
GPU به‌صورت پیش‌فرض غیرفعال است. در حالت غیرفعال، به Ollama درخواست استفاده از CPU به‌جای GPU داده می‌شود. این گزینه به‌تنهایی سخت‌افزار را خاموش نمی‌کند.
هر سقف مستقل است و از ۱۰ تا ۹۵ درصد قابل تنظیم است. CPU علاوه بر پایش، تعداد thread را هم محدود می‌کند. RAM و GPU هنگام شروع درخواست پایش می‌شوند؛ این برنامه نمی‌تواند مصرف پردازش خارجی Ollama را به‌صورت سخت در سطح سیستم‌عامل محدود کند. پایش GPU در این نسخه با nvidia-smi برای NVIDIA انجام می‌شود؛ اگر GPU قابل‌شناسایی نباشد، سقف GPU قابل اعمال/تأیید نیست.
بودجهٔ مؤثر از RAM واقعاً در دسترس پس از کسر حاشیهٔ امن محاسبه می‌شود و از سقف بالا بیشتر نمی‌شود؛ این مقدار رزرو اجباری RAM یا محدودیت سخت سیستم‌عامل نیست.
