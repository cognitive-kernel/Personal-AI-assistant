سقف مستقل استفاده از منابع سخت‌افزاری
GPU به‌صورت پیش‌فرض غیرفعال است. در حالت غیرفعال، به Ollama درخواست استفاده از CPU به‌جای GPU داده می‌شود. این گزینه به‌تنهایی سخت‌افزار را خاموش نمی‌کند.
هر سقف مستقل است و از ۱۰ تا ۹۵ درصد قابل تنظیم است. CPU علاوه بر پایش، تعداد thread را هم محدود می‌کند. RAM و GPU هنگام شروع درخواست پایش می‌شوند؛ این برنامه نمی‌تواند مصرف پردازش خارجی Ollama را به‌صورت سخت در سطح سیستم‌عامل محدود کند. تشخیص GPU چندسازنده‌ای است و از ابزارهای درایور و شمارنده‌های عمومی سیستم‌عامل استفاده می‌کند؛ اگر فقط نام کارت شناسایی شود اما معیار مصرف/حافظه در دسترس نباشد، آن معیار «نامشخص» نمایش داده می‌شود. وضعیت واقعی استفادهٔ Ollama از GPU از اندازهٔ حافظهٔ VRAM تخصیص‌یافته در /api/ps گزارش می‌شود.
بودجهٔ مؤثر از RAM واقعاً در دسترس پس از کسر حاشیهٔ امن محاسبه می‌شود و از سقف بالا بیشتر نمی‌شود؛ این مقدار رزرو اجباری RAM یا محدودیت سخت سیستم‌عامل نیست.
